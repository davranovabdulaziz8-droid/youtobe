## Барча видеолар учун умумий қоида

1. Видео ташхис қўймайди ва даволаш буюрмайди. Мақсад: маърифат, профилактика ва вақтида шифокорга мурожаат қилиш.
2. Ҳеч бир таҳлил «ҳамма топшириши шарт» деб айтилмайди. Текширув ёш, хавф омиллари, шикоят ва клиник кўрсатмага қараб танланади.
3. Ҳар бир рақам ва даъвонинг манбаси [06-manbalar.md](06-manbalar.md) да бор. Нашрдан олдин сценарийни соҳа шифокори текширади ва Ўзбекистон Соғлиқни сақлаш вазирлигининг амалдаги клиник протоколлари билан солиштиради.
4. Ҳар бир видео тавсифига қуйидаги огоҳлантириш қўйилади:

> ⚠️ Ушбу видео фақат маърифий мақсадда тайёрланган ва шифокор кўригини алмаштирмайди. Ташхис ва даволаш фақат шифокор томонидан белгиланади. Шошилинч ҳолатда 103 рақамига қўнғироқ қилинг.
